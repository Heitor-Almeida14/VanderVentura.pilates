# VanderVentura Pilates & Fisioterapia — Digital Experience

Experiência digital premium, cinematográfica e de alta conversão desenvolvida para o estúdio **VanderVentura Pilates & Fisioterapia**, localizado na Av. Cupecê, 2875 (Salas 4 e 6) – Jardim Prudência / Cidade Ademar, São Paulo - SP.

Inspirado na direção de arte, na tipografia monumental e nas microinterações de alta performance do site [landonorris.com](https://landonorris.com/).

---

## ⚡ Diferenciais & Funcionalidades

- **Identidade Visual Premium**:
  - Paleta com Off-white (`#F5F5F0`), Preto profundo (`#0C0E0C`), Carvão (`#161915`) e Verde-Limão Elétrico (`#D1FF00`).
  - Tipografia de alto impacto (*Syne*, *Plus Jakarta Sans*, *Space Grotesk*).
  - Recortes angulares orgânicos e máscaras arquitetônicas.
- **Hero Cinematográfica**:
  - Typo colossal com composição assimétrica e fotografia de estúdio em alta definição.
  - Badges oficiais de parceiros (**Wellhub / Gympass** e **Totalpass**).
  - Telemetria de atendimento (Máx. 3 alunos por fisioterapeuta, nota 4.9★ no Google).
- **Kinetic Marquee**:
  - Banner dinâmico contínuo com alta velocidade e tipografia grotesca estendida.
- **Apparatus Showcase Interativo**:
  - Navegação entre Reformer com Torre, Cadillac Trapézio, Wunda Chair, Ladder Barrel e Spine Corrector, com especificações clínicas e musculares.
- **Simulador de Alinhamento Biomecânico (Before & After)**:
  - Comparador interativo de postura em tempo real com controle deslizante e diagnóstico anatômico.
- **Planos, Passes & Calculadora de Frequência**:
  - Guia completo de utilização de Wellhub e Totalpass com check-in simplificado.
  - Planos particulares (Semestral, Trimestral e Experimental) com seletor de sessões semanais.
- **Simulador Interativo de Agendamento**:
  - Escolha de turno (Manhã, Tarde, Noite, Sábado), foco clínico e modalidade de acesso, com disparo direto e personalizado para o WhatsApp da recepção `(11) 91235-9659` com chuva de confetti.
- **Galeria & Integração com Instagram**:
  - Fotos de estúdio em alta resolução e conexão direta com o perfil oficial `@vanderventura.pilates`.
- **Localização & Rotas 1-Click**:
  - Links instantâneos para abrir no Waze e no Google Maps na Av. Cupecê, 2875.
- **Cursor Customizado & Acessibilidade**:
  - Cursor cinético reativo com atração magnética em botões no desktop e suporte total a touch no mobile.

- **Vite 6**

- **Lucide React**
- **Canvas Confetti**
- **Google Fonts** (Syne, Plus Jakarta Sans, Space Grotesk)

## 🚀 Como Executar Localmente

1. Abra a pasta do projeto no terminal ou no VS Code:
   ```bash
   cd VanderVentura.pilates
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Para compilar o build de produção:
   ```bash
   npm run build
   ```
